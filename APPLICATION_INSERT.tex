To engage directly with the operational challenges of the position, I developed
\href{https://github.com/pkd-45/dsa-hi-survey-ops}{\texttt{dsa-hi-survey-ops}},
a catalogue-aware planning and validation sandbox for DSA H\,\textsc{i}
observations. The framework optimises the placement of a fixed spectral-line
zoom product while propagating barycentric motion, redshift uncertainty,
expected line width, illustrative RFI occupancy, and source priority. It also
evaluates seasonal Doppler sensitivity and treats evolving public instrument
values as configurable dated snapshots rather than fixed design claims. The
cube-validation layer tests continuum subtraction, flagging, channel averaging,
and quantisation through integrated H\,\textsc{i} flux, velocity centroid,
$W_{50}$, projected position angle, completeness, and purity. A FITS-cube
adapter extends injection--recovery to existing cube backgrounds using
calibrated matched-filter S/N and paired-background measurements, with explicit
strict-versus-grown-mask and compression checks. The release includes seventeen
deterministic tests, machine-readable reports, continuous integration, and a
clear statement that it is an independent methods demonstration rather than
official DSA software or a performance forecast; no named real-survey result is
claimed until the adapter is run and archived on a downloaded public cube.
