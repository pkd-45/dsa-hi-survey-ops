# Public sources used for the project design

Accessed 12 July 2026.

1. Current Deep Synoptic Array overview: radio-camera architecture; detailed product list containing a 4096 x 8 kHz tuneable extragalactic H I zoom product; summary table containing 4192 x 8 kHz; observing-strategy text containing 20-minute blocks.
   https://www.deepsynoptic.org/overview

2. Earlier DSA reference snapshot: H I spectral products including 4192 x 8 kHz and 15-minute observing blocks.
   https://www.deepsynoptic.org/overview-1

3. DSA-110 public instrument specifications: 1280-1530 MHz and 8192 channels.
   https://www.deepsynoptic.org/instrument

4. Bonn Radio Astronomy and Interstellar Medium group projects, including PHANGS, MHONGOOSE, and WALLABY.
   https://astro.uni-bonn.de/en/research/radioastronomy-ism/research

5. PHANGS-ALMA data-processing and pipeline paper: simulations, quality assurance, and broad-versus-strict masks.
   Leroy et al. 2021, arXiv:2104.07665

6. EBHIS RFI mitigation.
   Floeer, Winkel & Kerp 2010, arXiv:1007.2328

7. EBHIS automated source finding, parametrisation, and classification.
   Floeer, Winkel & Kerp 2014, arXiv:1408.2079

The project is independent and does not claim endorsement by DSA, Caltech, AIfA, MPIfR, PHANGS, or EBHIS. Public instrument values are represented as configurable dated snapshots rather than final-design claims.

8. SoFiA-2 project wiki: public test H I data cube and reference outputs used as
   a recommended external validation target for the FITS adapter.
   https://gitlab.com/SoFiA-Admin/SoFiA-2/-/wikis/Home

9. Westmeier et al. 2021, SoFiA 2: injection tests in genuine ASKAP data,
    completeness/reliability, source fragmentation, and recovered H I parameters.
    arXiv:2106.15789
